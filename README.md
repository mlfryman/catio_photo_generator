# Catio Photo Generator
Generates a PDF of cat photos in a 2x3 layout

# 🚀 How to Run

### 1. Clone the repository:
```bash
git clone https://github.com/mlfryman/catio_photo_generator.git
cd catio_photo_generator
```

### 2. Create a virtual environment & install dependencies:
```bash
python3 -m venv venv
source venv/bin/activate   # Mac/Linux
venv\Scripts\activate      # Windows
pip install -r requirements.txt
```

### 3. Run Scripts
```bash
python3 make_cat_photo_pdf.py
```

The final output will be: './output/catio_cat_photos.pdf'
